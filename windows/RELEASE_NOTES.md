# Windows x64 單次注音查字測試版（70.1.1）

中文模式依序按 `'`、`;` 就能用標準注音查嘸蝦米碼。例如輸入「ㄒㄧㄚ」並按空白，候選會列出目前字表中主要讀音相符的字及對應字碼。上下鍵移動後按 Enter，或按數字即可選字，空白翻頁。選完立即恢復一般輸入。候選中的 Backspace 可返回組音修正，Esc 可隨時取消此次查詢。

## 嘸．改 R70 Windows x64 預發布版

- 使用 WiX Burn 安裝程式與 Windows Installer MSI；安裝程式名稱為 `LiuKai-win-setup.exe`，含嘸．改圖示與安裝前說明。
- 修正 Windows Terminal／WSL 中單按 Shift 切換中英偶發失效：放開事件遺失時可修復殘留的 Shift 狀態，左右 Shift 判斷使用按鍵事件產生時的狀態，並相容於放開事件缺少掃描碼的情況。
- 新增可選的 Shift 放開事件診斷紀錄；預設關閉，不記錄輸入文字。
- 在中文模式按 `'`，輸入已知同音字的字碼後按空白，可開啟同音字清單並查看字碼；上下鍵選字、Enter 輸出，空白翻頁，數字選字。
- 支援較長英文輸入後按 Enter 送出。

安裝需要 Windows x64，並使用同一個 Windows 帳戶完成管理員授權。升級既有版本時請執行 `LiuKai-win-setup.exe`；獨立 MSI 不會執行舊版升級。安裝器會檢查舊版是否符合安全升級條件；若有舊版檔案、未完成交易或無法確認的資料，安裝會停止並保留現況。請先儲存工作；舊版卸載程序可能需要關閉使用輸入法的程式。移除本版本時，安裝程式不會主動關閉其他程式，成功卸載後需重新啟動 Windows 以清除舊檔。若 Windows 不允許移動使用中的檔案，卸載會停止並保留診斷紀錄。

安裝程式會在本機產生 Windows Installer 日誌。已實測的前置檢查失敗及複製檔案後的 MSI 失敗會嘗試自動建立診斷 ZIP；啟動程式本身失敗或無法執行回復時，可能無法建立 ZIP。若安裝失敗，請保留日誌與交易紀錄供診斷。此版本為預發布版，每台電腦的實際安裝與使用狀況仍需驗證。

R70 候選安裝檔已在本機從 69 測試版升級成功，安裝 DLL 雜湊與註冊路徑核對正確；新開的記事本載入 R70 DLL，快速 Shift 切換與英文輸入正常。與 R70 同源的 69 測試版也已在 Windows Terminal／WSL 實測快速連按同一顆及左右 Shift、切換視窗後返回，均正常。R70 正式封裝通過 MSI 內容與安裝畫面驗證；另一台電腦仍應實際測試安裝與輸入，長期使用中是否完全排除偶發漏切也需繼續觀察。

安裝檔尚未簽署 Authenticode。Google Drive 曾限制舊安裝檔，判定原因尚未確認，不能保證新檔案不會受到限制。
