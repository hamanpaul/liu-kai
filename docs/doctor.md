# Doctor 本機診斷

Doctor 用來回查偶發的輸入、候選或中英切換問題。預設關閉，在設定頁開啟並確認後才收集，之後會記住選擇。診斷保存在本機，不會自動上傳。

目前以事件收集、輕量統計與健康狀態為主，不會自動推斷問題根因。匯出時整理指定時間範圍、版本與缺漏摘要，再由開發者分析紀錄；沒有背景 AI 分析。

## 開啟與查看狀態

Android 在嘸．改設定頁的「Doctor 診斷」操作。Windows 在右下角嘸．改圖示按右鍵，選單顯示目前版本、目前使用者的 Doctor 資料夾路徑及設定入口；在 Doctor 設定視窗操作。

Windows 設定與背景收集以一般使用者權限執行。若以系統管理員權限啟動設定而無法確認背景狀態，請關閉該視窗，再從一般桌面開啟。停用 UAC、沒有一般 Medium 權限程序的環境未納入驗收。

設定頁會分別顯示是否開啟、是否正在收集、保留的時間範圍及缺漏。缺漏數包含到期或達到容量上限後自動淘汰的舊紀錄，判讀時請一併查看保留時間範圍。若顯示中斷或無法確認狀態，請保留固定原因碼；開關已開啟不代表背景寫入一定成功。

Android 保留較多舊紀錄時，冷啟動後可能暫時顯示關閉；背景完成恢復後才顯示原本的設定。在顯示「收集中」之前，尚未開始收集。

## 遇到問題時

1. 選「標記剛才的問題」，或指定發生時間；不用重新輸入原本的文字。
2. 確認前後時間區間。預設包含問題前五分鐘與後三十秒，可以自行調整。
3. 建立預覽，查看實際可用的時間與缺漏，再選儲存位置。
4. 若要提供給開發者分析，由你自行分享存出的 ZIP。

預覽與存出的 ZIP 使用同一份固定內容。同時只保留一份待確認匯出，取消或逾期會刪除暫存。清除後，原本開著的預覽會失效，需重新建立。

## 停用、清除與容量

停用會停止新紀錄、丟棄尚未落盤的佇列，並保留既有檔案。清除才會刪除診斷紀錄與待確認匯出；只有實際清理完成才顯示成功。清除未完成時會停止收集、封鎖舊紀錄的讀取與匯出，請排除顯示的錯誤後再次清除。已保存的清除要求會在重新開啟後繼續；若儲存空間連清除要求都無法寫入，則無法保證重新開啟後仍保留該要求。

原始紀錄最多 32 MiB、最長七天，先達到的限制會先淘汰舊片段，所以不保證能保留完整七天。待確認 ZIP 最多 32 MiB，原始紀錄加暫存合計最多 64 MiB。你已另存的 ZIP 由你自行管理，不受清除與自動淘汰影響。

## 記錄範圍

Doctor 保留狀態、固定事件類別、時間、階段耗時與錯誤碼，用來關聯同一次輸入操作。格式沒有輸入文字、字碼、候選字、原始按鍵、座標、周邊文字、剪貼簿、文件、視窗標題或程序完整路徑欄位。

密碼、私密與未知欄位停止逐鍵記錄，只保留與按鍵無關的健康狀態及生命週期。判斷依宿主提供的欄位種類；未宣告的密碼提示可能無法辨識。

Windows Terminal 預設未提供欄位種類時只記健康狀態；需要輸入階段紀錄時的選用相容設定與密碼提示限制，見 [Windows 說明](../windows/README.md#terminal-的欄位資訊)。

Android Doctor 已在 0.1.1 發布；Windows Doctor 正式包與宿主驗收仍待完成，兩端以同一[共用議題](https://github.com/hamanpaul/liu-kai/issues/11)追蹤。
